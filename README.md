# Expense Tracker

A simple, clean, single-page expense tracking application that runs entirely in the browser. Add, edit, delete, filter, and sort your expenses with multi-currency support and a dark/light theme.

## Features

- Add, edit, and delete expenses
- Categorize expenses (Food, Transport, Shopping, etc.)
- Filter by category and sort by date or amount
- Multi-currency support (20+ currencies including USD, EUR, GBP, NGN, ZAR, and more)
- Light / dark theme toggle
- Persistent storage via localStorage
- Responsive design

## Technologies Used

- HTML5
- CSS3 (with custom properties for theming)
- Vanilla JavaScript
